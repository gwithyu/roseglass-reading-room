# Roseglass 共读室

**把课件打开，把不懂的地方指出来，和自己的 AI 一起读。**

一个**源码公开可查看、但采用限制性许可**的 PDF / PPTX 阅读与图文共读工具。玫瑰棕磨砂玻璃界面，支持重点定位、全文搜索、书签与笔记；聊天内版本还提供框选、整页讲解和中英德离线 OCR。

## 它能做什么

- **读课件：**翻页、适应整页 / 适应宽度、手动缩放，保持页面原比例。
- **指出重点：**点击词句、公式或图形；聊天内 MCP 版还可拖动框选、选择整页。
- **图文一起读：**把真实页图、相关文字与位置交给自己的聊天。框选时可附选区高清图。
- **接着学：**搜索全文，保存书签和本页重点；长 PDF 可按段发送文字、按需发送页图。
- **读扫描页：**MCP 版内置中文、英文、德语离线 OCR，保留真实图像与待核对的识别文字。

## 选择适合你的版本

| | 独立网页版（仓库根目录） | 聊天内 MCP 版（`mcp-reader/`） |
|---|---|---|
| 文件 | PDF、PPTX | PDF；PPTX 请先导出 PDF |
| 阅读、搜索、笔记 | 支持 | 支持 |
| 点选 / 框选 / 整页 | 点选、当前页导出 | 三种范围均支持 |
| 扫描文字识别 | 尚未接入 | 中英德离线 OCR |

| 是否需要 AI API Key | 阅读不需要 | 阅读和 OCR 不需要；AI 讲解取决于自己的聊天服务 |

## 快速开始

### 先在浏览器读课件

下载仓库 ZIP，或克隆后启动一个静态服务器：

```bash
git clone https://github.com/gwithyu/roseglass-reading-room.git
cd roseglass-reading-room
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080` → 点击「打开课件」→ 选择自己的 PDF 或 PPTX。

要让 AI 看图，使用「图文共读」。若页面提示宿主不支持，导出当前页 PNG，并把图片与文字一起附到自己的聊天中。**仓库页面本身不是阅读器入口**；静态托管需另行配置。独立网页版首次使用会从 CDN 加载解析库。

### 想在聊天里直接点选、框选

进入 [`mcp-reader/README.md`](mcp-reader/README.md)，按文档构建并部署自己的 MCP 服务，再连接兼容的聊天宿主。此版本将页面图像、文字、页码、文档指纹和选区记录关联发送；不会在每次提问时上传整本书的全部高清页图。

## 隐私与使用边界

- 文件解析在本地浏览器进行；MCP 版 OCR 也在本地进行，不调用第三方识别接口。
- 只有你明确点击发送或导出，才向聊天提供相应内容。聊天服务如何保留文件，由该服务自己的政策决定。
- 笔记和阅读位置属于浏览器本地数据。隐身模式、清理站点数据或换设备可能影响恢复；重要内容请导出或复制书签保存。
- 自动识别可能误读公式、表格与文字。识别结果会标记为待核对，页图仍是视觉讲解依据。
- “上传成功”“宿主接受请求”不等于模型已经看见图片。若 AI 无法描述图像内容，先核对附件，不要把文字推断当作识图成功。

## 发布验证

本次公开版的 MCP 自动化检查覆盖 **72 项测试**：生成的 52 / 300 页 PDF、真实 PDF 渲染、扫描 PDF 的实际 OCR、中英德混合图片、坐标、图文关联、失败状态、搜索和书签。独立网页版另有本地逻辑与源码检查。

这些自动化结果不代表所有浏览器、聊天宿主、扫描质量或复杂公式均已验证。实际 ChatGPT 内的界面、沙箱限制与图片接收，仍需要在使用环境中核对。详见[发布说明](CHANGELOG.md)。

## 个人 API 共读（仅公开版）

每位使用者自行提供自己选定服务商的 API Key 与模型额度，在 Roseglass 内直接提问、追问，作者不提供公共付费 API，也不会代付费用。不需要额外跳转任何 AI 网站。当前支持 OpenAI、DeepSeek 与本机 Ollama（仅供用户自己的本地服务调用）。

PDF.js 已随仓库提供，PDF 页面阅读不需要境外 PDF.js CDN；PPTX 仍使用外部解析模块，受限网络下可能需要先转换为 PDF。

## 可选：本机 AI API 共读（无需托管服务）

公开版新增独立的 **本机 API 模式**，不改变原有 ChatGPT 共读、搜索、书签和页面导出。**作者不承担任何 API 调用或托管费用，项目没有共享的 AI 额度，也没有公共 AI 后端。**

需要 **Node.js 22+**，在仓库根目录运行：

```bash
node local-api/server.mjs
```

然后在本机打开 **http://127.0.0.1:8787**，选择 PDF/PPTX，点击「连接我的 AI API ↗」。页面继续在浏览器本地解析，只有点击「发送问题」才会提交当前页文本；真实页图必须另外勾选才发送。

- **不产生云端 AI API 费用的选择：** 用户自行安装并运行 Ollama、下载兼容视觉模型（默认 `llava`，可用 `ollama pull llava`），本机 API 代理会请求 `127.0.0.1:11434`。下载模型会使用磁盘与设备资源。
- **使用自己的云端额度：** 使用者在**自己电脑的终端环境变量**中配置 `OPENAI_API_KEY` 或 `DEEPSEEK_API_KEY`，并明确设置 `ROSEGLASS_ENABLE_CLOUD=1` 后才启动本机服务。界面仍需勾选自愿使用个人额度；默认服务端会阻止任何云端 AI 请求。OpenAI / DeepSeek 可能按各自政策收费；此选项不是免费额度承诺。密钥不会写入网页、仓库或浏览器存储，也不要提交到 GitHub。
- 目前 DeepSeek 连接为文字模式，不支持发送页图；OpenAI、Ollama 的实际视觉能力取决于所选模型。
- 本机服务只绑定 `127.0.0.1`，不接受跨站请求，不提供公共共享代理。若只打开 GitHub 静态版或使用 `python3 -m http.server`，本机 AI 按钮会提示启动 Node 服务；原有阅读器继续可用。
- 临时 AI 对话只在当前标签页内存中维护，不上传到作者服务器。云端模型处理已明确发送的内容时，遵循用户选择的 AI 提供商的条款与隐私政策。

开发和验收使用本机模拟服务，不需要 GitHub Actions 或真实付费 API：

```bash
node --test tests/api-*.test.mjs
```

此功能只属于 **公开版的独立网页版**。它不使用、不连接也不包含作者的私人 ChatGPT Site、g-mind、私人记忆或密钥。
