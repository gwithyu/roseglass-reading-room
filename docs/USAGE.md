# 使用与隐私

## 第一次使用

普通阅读选择根目录独立网页版；需要在聊天中直接圈出选区的用户选择 MCP 版。两者共享阅读目标，但部署方式和能力不同，请不要把根目录页面当作已接好的聊天插件。

## 共读顺序

1. 打开自己的课件，确认页码和画面正确。
2. 点击想问的位置，或在 MCP 版拖动框选 / 选择整页。
3. 写问题，点击发送；查看当前聊天中实际出现的文字和图片。
4. 若 AI 说看不到图，先检查附件。独立版可导出 PNG 手动上传。
5. 将重要结论和未解决的问题写入本地笔记；离开前复制或导出书签。

## 中英德扫描页

离线 OCR 目前在 MCP 版内提供。没有原生文字层时会尝试识别；失败仍可发送真实页图。德语测试包含 ä / ö / ü / ß。识别文字标记为待核对，置信度不是正确率保证；数学公式、低清照片、复杂表格和手写内容应结合页图核对。

## 长文档

文档索引和全文搜索不代表全文已进入聊天。文字按宿主接受的请求分段推进；页图按当前阅读页发送。更换聊天后不恢复“已发送”计数，以免把上一段聊天的状态冒充当前聊天的接收证明。笔记和书签可帮助续读，但不是无限上下文。

## 本地与外部服务

阅读位置、笔记和书签保存在用户浏览器或手工导出的文件中。MCP 版不包含远程持久化笔记服务器。选择发送后，文字与图片将进入用户选择的聊天服务。独立版的公共解析依赖来自 CDN，敏感部署可自行托管依赖。不要在公开 Issue 上传未获许可的课程材料或隐私信息。
