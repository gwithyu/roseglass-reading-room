# Roseglass 公共插件分发进度与普通用户安装说明

> 状态：**候选部署 / 尚未通过 ChatGPT 插件目录审核**。本仓库地址不是可直接安装的 ChatGPT 插件入口。请勿让普通用户在 iPad 上安装 Git、Node 或 Python。

## 预期给 Plus 用户的最终体验

在 ChatGPT 的插件目录找到 **Roseglass 共读室** → 安装 → 在自己的聊天中 @Roseglass → 选择 PDF → 点选、框选或整页提问。**讲解使用用户自己的 ChatGPT 账户**；不是共享开发者的 Plus、私人版、g-mind 或 API 额度。PPTX 需要先导出为 PDF 才能进入聊天内 MCP 版。

## 公开发布需要哪些条件

1. 启用独立的公共 HTTPS MCP 地址 `/mcp`，测试 initialize、tools/list、resources/read、图片附件及 iPad UI 显示。不要把私人 Site ID、令牌、g-mind 服务或用户资料加入公开部署。
2. 使用官方开发者身份完成验证；具备 `api.apps.write` 等发布权限，并按最新 [官方提交说明](https://developers.openai.com/plugins/deploy/submission) 上传对应插件材料。准备公开可访问的隐私说明、图标、中文英文说明及审核截图。
3. 通过 OpenAI 的审核并真实安装到一个独立的 Plus 测试账号。**审核前不可宣称“Plus 已能直接安装”；即便审核通过也要验证特定地区和移动端支持。**
4. 上线后宣传分享的是正式插件目录入口，不是单独把源码仓库地址发给普通学生。

## 暂时可用的方式

独立网页版可以在本地静态托管后使用，但它不是聊天内的插件。没有官方目录上架前，在普通 Plus 账号的 ChatGPT 中输入本仓库 URL，不会自动安装插件，也不需要让使用者自己部署 MCP。

## 测试和费用边界

- 本分支只接入公共托管适配器，Vercel 的 `/mcp` 处理不信任互联网提交的所有者鉴权头；管理接口仍默认关闭。
- 不启用 GitHub Actions 工作流，也不使用开发者的私人 OpenAI API Key。
- 大型资源通过流式响应传输以避免函数缓冲体积限制；实际部署仍须验证构建结果、兼容性和计费状态。
- 发布前，必须完成跨账户隔离、日志不泄露、异常输入、移动端和回滚验收。
